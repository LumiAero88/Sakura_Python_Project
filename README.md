# 🌸 Sakura Bloom Animation

![Vorschau der Animation](Screenshot%202025-12-06%20171846.png)

A calming, generative animation of falling Cherry Blossoms (Sakura), written in Python.

## 📝 Description
This project simulates a peaceful evening scene under a cherry blossom tree. It features randomly generated branches, a "bokeh" background effect, and individual petals that drift, sway, and spin as they fall.

The animation runs entirely in the standard Python library, making it lightweight and easy to run.

## ✨ Key Features
* **Physics Simulation:** Petals follow a natural falling pattern with wind drift and sine-wave swaying.
* **Generative Elements:**
    * **Branches:** The tree branches are procedurally drawn, meaning they look slightly different every time.
    * **Petals:** Each blossom has randomized size, speed, and color variations (from soft pink to white).
* **Visuals:** Set against a deep blue evening sky (`#142034`) with subtle background lights.

## 🛠️ Built With
* **Python 3.x**
* **Tkinter** (Standard GUI library for Python)
* `math` & `random` modules

## 🚀 How to Run
Since this uses the standard library, no external installation is required.

1.  Make sure you have Python installed.
2.  Download the file `Sakura.py`.
3.  Run it from your terminal:
    ```bash
    python Sakura.py
    ```
